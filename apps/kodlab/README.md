# КодЛаб · JavaScript

Монгол хэлтэй 6–8-р ангийн JavaScript дадлага, мэдлэгийн сорил. Энэ аппын эх код Next.js репозиторийн нэг npm workspace юм.

## Ажиллуулах

Репозиторийн үндсэн хавтсанд:

- `npm install` — Next.js болон КодЛаб-ийн хамаарлыг нэг түгжээ файлаар суулгана.
- `npm run dev` — КодЛаб-ийг бэлтгээд Next.js хөгжүүлэлтийн серверийг эхлүүлнэ. `/kodlab` хаягаар орно.
- `npm run kodlab:dev` — зөвхөн КодЛаб-ийн кодыг шууд шинэчлэн хөгжүүлэх. `http://localhost:4173/kodlab/` хаягаар нээнэ.
- `npm run kodlab:build` — шинэчилсэн КодЛаб-ийг `public/kodlab/` дотор бэлтгэнэ.
- `npm run kodlab:test` — КодЛаб-ийн автомат шалгалтууд.
- `npm test` — КодЛаб болон Next.js-ийн шалгалтуудыг хамтад нь ажиллуулна.
- `npm run build` — эхлээд КодЛаб, дараа нь Next.js-ийн production хувилбарыг бэлтгэнэ.

`npm run kodlab:dev`-ээр кодыг өөрчилсний дараа Next.js сервер дээрх хувилбарыг шинэчлэх бол `npm run kodlab:build` ажиллуулаарай.

## Бүтэц

- `src/content.js` — 74 дасгал, 20 сорилын асуулт, жишээ хариу, шалгах өгөгдөл.
- `src/main.js`, `src/style.css` — хичээл, кодын редактор, сорил, сурагчийн ID дэлгэц.
- `src/engine.js`, `src/runtime.js` — Acorn шалгалт болон sandbox iframe доторх Worker.
- `src/store.js` — сурагчийн ID тус бүрийн сервер болон браузер дахь хадгалалт.
- `tests/` — жишээ хариу, заагийн утга, сорилын оноо, сурагчийн ахиц тусгаарлах шалгалтууд.
- `public/` — КодЛаб-ийн өөрийн дүрс.

## Сурагчийн ахиц

Сайт нээх бүрд ID оруулна. Ижил ID-гаар MongoDB-д хадгалсан ажлаа өөр компьютер дээр үргэлжлүүлнэ. Серверт хадгалсан төлөвийг дэлгэц дээр харуулна. Багшид тайлан болон кодоо татаж өгч болно.

Энэ апп `javascript-lab-8.mnafairy.chatgpt.site`-аас код эсвэл өгөгдөл татахгүй. Бүх код, хэв маяг, редакторын файлууд Next.js сервер дээр байна. Өмнөх нийтэд нээлттэй хувилбарыг энэ өөрчлөлт өөрчлөхгүй.

## Production

`public/kodlab/` нь үүсгэсэн файлууд тул Git-д хадгалахгүй. `npm run build` эхлээд JavaScript аппыг бэлтгээд, одоогийн Python болон Next.js төслийн build үйлдлийг ажиллуулна. Хичээл сонгох нүүр `/`, Python `/python`, Next.js хичээл `/next-classroom`, JavaScript дадлага `/kodlab` хаягтай.

Эх хувилбар: КодЛаб-ийн нийтэд нээлттэй хувилбар 4 (24 дасгал). Next.js integration нь `app/kodlab/route.ts` дотор байна.
